# منصة QR للمحلات | Shop QR & Smart Bio-Link Platform

منصة ويب متكاملة، سريعة واحترافية للمحلات، المقاهي، والمطاعم لإنشاء صفحة ذكية موحدة برمز QR تجمع كافة روابط التواصل، الخرائط، قائمة الطعام (المنيو)، وحسابات التواصل الاجتماعي مع أزرار سحب تفاعلية وتوليد بطاقات ستاند الطاولات الجاهزة للطباعة فوراً.

---

## 🌟 أبرز المميزات

- **🎯 أزرار سحب تفاعلية (Interactive Swipe Tracks)**: تجربة مستخدم ممتعة وسلسة تسحب فيها الزر للدخول مباشرة إلى واتساب، إنستغرام، تيك توك، خرائط Google، سناب شات، أو الاتصال الهاتفي، مع دعم النقر المباشر (Tap to open).
- **▣ توليد رموز QR عالية الدقة (HD PNG QR Codes)**: توليد رمز QR فريد لكل متجر مع زر تحميل فوري لصورة PNG عالية الجودة متوافقة مع الطباعة على الملصقات والستاندات.
- **🖨️ مولد ستاند الطاولات الجاهز للطباعة (Table Tent / Stand Generator)**: تصميم مخصص جاهز للطباعة بضغطة زر واحدة بدون الحاجة لمصمم جرافيك، مصمم بمقاسات مناسبة لستاندات الأكرليك وبطاقات الطاولات والاستقبال.
- **🎨 تخصيص الهوية البصرية**:
  - تدرج لوني مخصص يصل إلى 5 ألوان.
  - رفع شعار المحل (Logo) مع ضغط تلقائي ذكي لسرعة التحميل.
  - صورة غلاف بانر (Cover Banner).
  - صورة باركود أو قائمة الطعام (Menu Barcode).
- **🛍️ روابط ومتاجر مخصصة**: إمكانية إضافة حتى 5 مواقع أو متاجر إلكترونية (مثل سلة، زد، شوبيفاي، أو موقع رسمي) مع أيقونة السلة وألوان مخصصة.
- **📊 لوحة إحصاءات وتحليلات دقيقة**:
  - إجمالي مشاهدات الصفحة ومشاهدات اليوم.
  - تتبع النقرات على كل منصة بالتفصيل (واتساب، خرائط، انستغرام، اتصال، الخ).
  - تصفية الأحداث والرسوم البيانية.
- **⚡ وضع التشغيل الهجين (Cloud + Offline Demo Mode)**:
  - دعم قاعدة بيانات **Supabase** لتخزين المحلات والمستخدمين والأحداث السحابية.
  - وضع تجريبي محلي فوري (Demo Mode) يسمح باختبار وتجربة المنصة كاملة حتى قبل ربط قاعدة البيانات.
- **⚙️ واجهة تعديل الإعدادات من المتصفح**: نافذة إعدادات مدمجة تتيح إدخال مفاتيح Supabase وحفظها دون الحاجة لتعديل الكود البرمجي.
- **🔍 بحث وتكرار المحلات**: إمكانية البحث الفوري، تفعيل/تعطيل المحلات بزر واحد، ونسخ بيانات المحل (Duplicate) لإنشاء فروع جديدة بسرعة.

## 🗄️ خطوات إعداد قاعدة بيانات Supabase (لأول مشروع)

لتشغيل مشروعك الخاص بقاعدة بيانات حقيقية مجانية 100%:

### الخطوة 1: إنشاء مشروع جديد في Supabase
1. توجّه إلى [Supabase.com](https://supabase.com) وسجّل الدخول مجاناً.
2. اضغط على **"New Project"** وأدخل اسماً للمشروع وكلمة مرور لقاعدة البيانات.

### الخطوة 2: إنشاء الجداول وصلاحيات الحماية
1. من القائمة الجانبية في Supabase، اختر **SQL Editor**.
2. انسخ محتوى الملف `supabase_schema.sql` بالكامل والصقه في المحرر.
3. اضغط **RUN**. سيقوم السكربت بإنشاء:
   - جدول `shops` (المحلات بكافة تفاصيلها وروابطها وألوانها).
   - جدول `analytics_events` (مشاهدات الصفحة ونقرات الأزرار).
   - سياسات الأمان والحماية (Row Level Security - RLS).
   - الفهارس التلقائية ومحفزات التحديث (Triggers).

### الخطوة 3: إنشاء حساب المسؤول (Admin User)
1. من القائمة الجانبية، توجّه إلى **Authentication** -> **Users**.
2. اضغط **Add User** -> **Create User**.
3. أدخل بريدك الإلكتروني وكلمة المرور، وتأكد من تفعيل خيار **Auto Confirm User**.

### الخطوة 4: ربط المفاتيح
1. من القائمة الجانبية، اذهب إلى **Project Settings** -> **API**.
2. انسخ **Project URL** و **anon public key**.
3. يمكنك استخدامها بأي من الطرق التالية:
   - **الطريقة الأسهل**: افتح المنصة في المتصفح، اضغط على **"⚙️ إعدادات الربط مع Supabase"**، والصق الرابط والمفتاح.
   - **أو عبر ملف `.env`**:
     ```env
     SUPABASE_URL=https://your-project.supabase.co
     SUPABASE_ANON_KEY=your-anon-public-key
     ```

## 🛡️ النظام الأمني والتمويه السيبراني (Cybersecurity & Deception Architecture)

تم تزويد المنصة بحصانة أمنية مشددة وفقاً لأحدث معايير الأمان ومكافحة هجمات القوة الغاشمة (Brute-Force Protection):

1. **بيانات الاعتماد السرية للإدارة العليا**:
   - **اسم المستخدم**: `AL`
   - **كلمة المرور (الباسورد)**: `AL`
   - يتم تشفير كلمة المرور فورياً بتقنية **SHA-256** أحادية الاتجاه المشفرة برمجياً لمنع حفظها كنص عادي.
2. **نظام التمويه الأمني الذكي (Deception / Honeypot Defense)**:
   - عند إدخال أي كلمة مرور خاطئة من قبل أي متطفل أو مهاجم، لن يخبره النظام بأن كلمة المرور قصيرة أو بسيطة.
   - يعرض النظام رسالة تمويهية مضللة:  
     `"خطأ أمني: كلمة المرور تتكون من أكثر من 8 خانات (رموز وأرقام وحروف)"`
   - هذا التمويه السيبراني يشتت أدوات الفحص التلقائية ومحاولات التخمين ويدفعهم لتجربة كلمات مرور طويلة ومعقدة بعيداً تماماً عن كلمة السر الحقيقية.
3. **طبقات الحماية والتشفير**:
   - **تشفير SHA-256 عبر Web Crypto API وخوارزمية Node.js Crypto**: تشفير ثنائي الجهتين (Client & Server).
   - **حماية ضد هجمات توقيت المعالجة (Timing Attack Mitigation)**: تأخير زمني اصطناعي موحد لإحباط قياس سرعة الاستجابة.
   - **ترويسات أمان متقدمة (Security Headers)**:
     `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `X-XSS-Protection`, `Strict Referrer-Policy`.
   - **إخفاء هوية التقنية (Hide Fingerprint)**: إيقاف ترويسة `x-powered-by: Express`.
   - **تحديد معدل الطلبات (Rate Limiter)** لمكافحة الهجمات المؤتمتة.

### 🌐 2. خطوات رفع المشروع وربطه بدومين خاص (Custom Domain)

يمكنك تشغيل المنصة على دومين خاص بك (مثل `qr.yourdomain.com` أو `yourdomain.com`) مجاناً عبر منصة **Vercel** أو **Netlify** خلال دقائق:

#### الخيار (أ): الرفع على Vercel (موصى به - أسهل وأسرع)
1. قم بإنشاء حساب مجاني على [Vercel.com](https://vercel.com).
2. اضغط **Add New Project** واختر مستودع الـ GitHub الخاص بك `qr-shop-platform`.
3. اضغط **Deploy**. في غضون ثوانٍ سيصبح موقعك متاحاً على رابط عالمي مشفر بـ HTTPS.
4. **لربط الدومين الخاص**:
   - ادخل إلى إعدادات المشروع في Vercel: **Settings -> Domains**.
   - اكتب اسم الدومين الخاص بك (مثلاً: `qr.myshop.com` أو `myshop.com`) واضغط **Add**.
   - سيظهر لك Vercel سجل DNS (مثلاً `CNAME` يوجه إلى `cname.vercel-dns.com` أو `A Record` إلى `76.76.21.21`).
   - ادخل للوحة تحكم النطاقات في مزود الدومين الخاص بك (Namecheap, GoDaddy, Cloudflare, etc.) وأضف هذا السجل.
   - سيتم تفعيل الدومين وشهادة SSL المجانية تلقائياً!

#### الخيار (ب): الحماية والربط عبر Cloudflare (موصى به للأمان والسرعة)
1. سجل دخولك في [Cloudflare](https://dash.cloudflare.com) واضغط **Add a Site** وأدخل اسم نطاقك.
2. اختر الخطة المجانية **Free ($0)** وانقل خوادم الأسماء (Nameservers) لمزود الدومين الخاص بك.
3. في تبويب **DNS -> Records** أضف:
   - سجل **CNAME** باسم `qr` أو `@` والهدف `cname.vercel-dns.com` مع تفعيل السحابة البرتقالية **(Proxied)**.
   - تحصل فوراً على حماية ضد هجمات DDoS وتشفير SSL وتسريع CDN عالمي.

#### الخيار (ج): تفعيل الدومين داخل إعدادات المنصة
- بعد ربط الدومين، افتح المنصة واضغط على **"⚙️ إعدادات المنصة والدومين والأمان"** أو زر **"🌐 دليل ربط الدومين والاستضافات و Cloudflare"**.
- توجّه إلى تبويب **"الدومين المخصص"** واكتب رابط موقعك (مثلاً: `https://qr.myshop.com`).
- سيتم فوراً تحديث كل الأزرار، روابط المتاجر، رموز QR، وبطاقات الطاولات لتطبع وتنشر باستخدام دومينك الرسمي.

## 🛡️ منظومة الأمان والتحقق البيومتري المزدوج (Biometric & Multi-Layer Security)

تم تزويد المنصة بنظام أمان سيبراني مشدد يمنع تماماً دخول لوحة تحكم الإدارة إلا للمسؤول المخول:
1. **المصادقة الثلاثية (Triple Authentication Layer)**:
   - كلمة المرور المشفرة بـ SHA-256 (`AL`).
   - تمويه أمني ضد المخترقين (Fake decoy error stating password must be > 8 characters).
   - التحقق البيومتري الإلزامي بواسطة **بصمة الوجه (Face ID)** ومطابقتها حياً عبر الكاميرا مع صورة المسؤول المعتمدة (`admin_face.jpg`).
   - خيار التحقق عبر **بصمة الإصبع (Touch ID / WebAuthn)**.
2. **سجل تدقيق بيومتري (Audit Log)**: تسجيل زمني دقيق لكل عملية دخول ناجحة أو فاشلة.
3. **تخصيص البصمة وصورة الوجه**: إمكانية التقاط صورة وجه جديدة مباشرة عبر الكاميرا أو رفع ملف من تبويب "🛡️ البصمات والأمان" في إعدادات المنصة.
